Golden Hour Cover Studio — turn your photo into GTA 6-style cover art. Load your own photo, crop and position it across four multi-panel layouts, write a bold caption, pick a sunset, neon or noir grade, and export a PNG in 1080×1080, 1080×1350 or 1920×1080. Built for the make.fun GTA 6 Cover Art bounty.

## Run it

```sh
node serve.ts
```
